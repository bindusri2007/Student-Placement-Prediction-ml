
# Student Placement Eligibility Prediction Using Machine Learning

## Project Description
This project predicts student placement status using a Random Forest
classification model based on academic performance, technical skills,
communication skills, backlogs and internship experience.

## Dataset
The dataset contains 1200 synthetically generated student records.
It is created for academic demonstration and is not real placement data.

## Features
- CGPA
- 10th Percentage
- Intermediate/Diploma Percentage
- Technical Skills Score
- Communication Skills Score
- Backlogs
- Internship

## Target
Placement_Status: Placed or Not Placed

## Algorithm
Random Forest Classifier

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly,
Scikit-learn, IPyWidgets and Joblib.

## Evaluation
- Accuracy: 77.08%
- Precision: 70.93%
- Recall: 67.03%
- F1 Score: 68.93%

## How to Run
1. Open the notebook in Google Colab.
2. Run the cells from top to bottom.
3. Use the interactive prediction section to enter student details.

## Disclaimer
The data is synthetic and the model is for educational purposes.
Its predictions should not be used for actual recruitment decisions.
